# 천하쟁패 삼국지

옛 삼국지 전략 게임 느낌의 브라우저 게임. 군주가 되어 천하를 통일한다.

- 바로 하기: https://hoon0808.github.io/sanguo-game/
- 폰: 가로·세로 모두 (세로는 위에 지도, 아래에 명령판). Safari(아이폰)·크롬(안드로이드)으로 연 뒤 「홈 화면에 추가」하면 주소창 없이 앱처럼 열리고, 한 번 연 뒤에는 인터넷 없이도 된다.
- PC: 위 주소를 크롬·엣지로 열면 된다.

이 저장소는 배포용 묶음이다. 원본은 비공개 저장소 `digitallk-tools/game/sanguo` 이며 `python3 tools/build-site.py <이 폴더>` 로 만든다.
